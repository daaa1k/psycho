# PSYCHO

KDL 2.0 を正本にして技術発表を編集し、全画面で表示する macOS アプリです。

## 起動

Rust と Xcode Command Line Tools がある macOS で実行します。

```sh
cargo run --features gui
```

引数に KDL ファイルを渡すと、その Presentation を開きます。引数がない場合は `examples/build-time.kdl` を表示します。

```sh
cargo run --features gui -- path/to/presentation.kdl
```

## 編集

- 左側の Slide 一覧を選ぶと、中央にプレビューが表示されます。
- Slide の追加・削除・上下移動は上部のボタンから行います。
- Element をクリックして選び、見出し・本文・箇条書き・コード・表示中の Caption はキャンバス上でダブルクリックして直接編集します。画像参照とコード言語は Inspector から変更します。
- 本文、コード、箇条書き、Caption は複数行で編集できます。箇条書きは1行ごとに項目になり、項目の追加・削除・並べ替えも Inspector から行えます。
- 2列を選ぶと Inspector に列内 Element の選択・追加が表示されます。Element はキャンバス上のドラッグで並べ替え、列の内外へ移動できます。列幅は境界のドラッグ、数値入力、`+5%` / `-5%` ボタンで調整できます。
- Rust、YAML、JSON、TOML のコードを構文色分けします。未指定または未対応の言語は通常色で表示します。
- Undo / Redo はツールバー、macOS の「編集」メニュー、または `Cmd-Z` / `Cmd-Shift-Z` で操作します。入力欄にフォーカスがある間は入力欄の履歴を先に戻します。
- 保存は `Cmd-S`、別名保存は `Cmd-Shift-S` です。別名保存先の既存ファイルは、macOS の保存パネルで上書きを確認した場合に置き換えます。別フォルダーへ保存すると、同じ Asset を指すよう画像パスを書き換え、Undo 履歴を消去します。
- Escape または別の操作へ移ると編集中の値を確定します。未保存のままウィンドウを閉じようとすると、保存・破棄・キャンセルを選べます。

保存時は編集対象の値だけを KDL 原文で置き換えます。コメント、改行、空白、raw string など未編集部分の表記を保持します。外部 KDL は定期確認し、未保存の編集や入力がなければ正常な変更を自動で読み直します。競合中は上書き保存と編集、Undo / Redo、発表を止めます。「外部変更を読み込む」から「編集を破棄して再読み込み」を選ぶと、外部ファイルへ切り替わります。再読み込みが失敗しても編集内容と履歴は保持し、成功した場合だけ履歴を消去します。

## 発表

「最初から発表」または「現在から発表」を選びます。全画面では Right / Down / Space / PageDown で次へ、Left / Up / PageUp で前へ進み、Escape で編集に戻ります。ポインターは動かすと表示し、2秒静止すると隠します。

画像は Presentation ファイルからの相対パスで参照します。静止 PNG、JPEG、WebP を表示します。欠落、破損、未対応形式、アニメーション画像は診断に表示し、問題が残っている間は発表を開始できません。

KDL 構文や Presentation Schema v0.1 のエラーはファイル名、行・列、該当行を表示します。診断を選ぶと、構文・Schema エラーでは読み取り専用の該当ソース行へ、画像や配置の診断では対象の Slide / Element へ移動します。外部でファイルが削除されたり無効になったりした場合は、最後の正常な表示と編集内容を保持し、現在のファイルと異なることを表示します。編集・上書き保存・発表は停止します。外部エディターで修正・復元して「外部変更を読み込む」を選び、正常に再読み込みできると編集を再開できます。初めから無効なファイルは部分プレビューせず、診断を表示します。
