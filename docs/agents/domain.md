# Domain docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs in `docs/adr/`. Create them only when the first term or decision is resolved.

Before exploring the codebase, read `CONTEXT.md` and relevant ADRs if they exist. Proceed when they do not yet exist. Use the glossary's terms in issues, proposals, and code. Surface any conflict with an existing ADR rather than silently overriding it.
