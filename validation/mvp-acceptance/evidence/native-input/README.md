# ネイティブ入力の検証

`native_input_acceptance.py` は中央の見出しをダブルクリックし、全文置換して保存する。保存したKDLが期待する文字列と完全一致し、未保存状態が解除されたことまで確認する。

実行した製品とバイナリのハッシュは `manifest.json` に記録した。`d96e55c` は main を基にした検証補助だけの変更で、Overviewの製品変更を含まない。実機試験は成功した。後続の証跡コミットは製品と補助の動作を変えない。

比較ログ2本は、別の統合版 `c8c3f83` の同一スクラッチプロセスで取得した。通常経路でフォーカスや選択が変わらなかった操作が、ネイティブイベントやメニューでは反映された。内部実装の原因までは断定しない。この補助で証明する全選択は編集メニュー経由であり、Cmd+Aのキー送信とは区別する。

macOS GUIをビルドし、既存の検証環境を準備してから、未使用の出力先で実行する。

```sh
python3 validation/mvp-acceptance/native_input_acceptance.py --output target/native-input --revision <build-revision>
```

GUIドライバーは一つだけ動かす。補助は所有するスクラッチPID、前面のアプリ、ウィンドウ内の座標を確認してから入力する。
