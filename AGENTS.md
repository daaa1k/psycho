# Agent instructions

Think in English and provide all answers in Japanese.

Always use Conventional Commits for git commit messages unless the user explicitly asks for a different format.

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. See `docs/agents/domain.md`.
